# Write a page

Write the page in Markdown, with the site's components in the sidebar: drag one in, or type `/`. The preview sits beside it, and **Ctrl+.** opens a component's form when you'd rather fill one in. Paste from Word, a web page or the Azure DevOps wiki and the formatting comes with it; **Open** changes a page that's already on the site. Every page is kept as a draft in this browser, with earlier versions to go back to. Download the page with its images and files as one bundle; nothing leaves your computer until you upload it, and **Add to site** shows you how. **Ctrl+/** lists the shortcuts.
