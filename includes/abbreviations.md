*[ACR]: Azure Container Registry
*[AFD]: Azure Front Door
*[AKS]: Azure Kubernetes Service
*[ALB]: Application Load Balancer (AWS)
*[APIM]: Azure API Management
*[ARM]: Azure Resource Manager, the deployment and management layer behind every Azure resource
*[ARN]: Amazon Resource Name, the unique ID of an AWS resource
*[AVD]: Azure Virtual Desktop
*[CIDR]: An IP address range written as address/prefix, such as 10.0.0.0/16
*[CLI]: Command-line interface
*[EC2]: Amazon Elastic Compute Cloud (virtual machines)
*[ECR]: Amazon Elastic Container Registry
*[ECS]: Amazon Elastic Container Service
*[EKS]: Amazon Elastic Kubernetes Service
*[FQDN]: Fully qualified domain name, such as app.example.com
*[IaaS]: Infrastructure as a service
*[IaC]: Infrastructure as code: Bicep, Terraform, CloudFormation and the like
*[IAM]: Identity and access management
*[KMS]: AWS Key Management Service
*[MFA]: Multi-factor authentication
*[NLB]: Network Load Balancer (AWS)
*[NSG]: Network security group (Azure): allow and deny rules for a subnet or network interface
*[OIDC]: OpenID Connect
*[PaaS]: Platform as a service
*[PIM]: Privileged Identity Management (Microsoft Entra): just-in-time admin roles
*[RBAC]: Role-based access control
*[RDS]: Amazon Relational Database Service
*[RPO]: Recovery point objective: how much data you can afford to lose
*[RTO]: Recovery time objective: how long you can afford to be down
*[S3]: Amazon Simple Storage Service
*[SaaS]: Software as a service
*[SCP]: Service control policy (AWS Organizations): the most an account's IAM policies can allow
*[SKU]: The size or tier of a service, such as Standard_D4s_v5
*[SLA]: Service-level agreement
*[SSO]: Single sign-on
*[TLS]: Transport Layer Security
*[UDR]: User-defined route (Azure)
*[VNet]: Virtual network (Azure)
*[VPC]: Virtual private cloud (AWS)
